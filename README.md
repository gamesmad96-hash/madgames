# MADGAMES.FUN

Phase 1 working browser-game portal starter.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Included
- Responsive homepage and game discovery
- Category routes
- Search
- Game detail/player shell
- Local playable demo game
- Favorites + recent history in localStorage
- Admin dashboard UI foundation
- SEO metadata foundation

## Next integrations
- Supabase database/auth/RLS
- GameDistribution publisher integration
- GameMonetize publisher integration
- Admin import queue
- GA4 / Search Console
